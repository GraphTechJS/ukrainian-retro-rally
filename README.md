# Ukrainian Retro Rally

Прототип сайту клубу **Ukrainian Retro Rally** / Автоклуб Москвич Київ.

## Стек

- React + Vite
- React Router
- CSS modules-подібні файли по компонентах

## Запуск

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
npm run preview
```

## Структура

- `src/components` — Header, Hero, EventTimeline, GalleryStrip, Footer тощо
- `src/pages` — головна, новини, події, екіпажі, галерея, партнери
- `src/data/content.js` — контент українською
