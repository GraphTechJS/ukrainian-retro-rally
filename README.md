# Ukrainian Retro Rally

Прототип сайту клубу **Ukrainian Retro Rally** / Автоклуб Москвич Київ.

- Репозиторій: https://github.com/GraphTechJS/ukrainian-retro-rally
- Демо: https://graphtechjs.github.io/ukrainian-retro-rally/

## Стек

- React + Vite
- React Router
- CSS по компонентах

## Запуск

```bash
npm install
npm run dev
```

Локально відкривайте: `http://localhost:5173/ukrainian-retro-rally/`

## Збірка

```bash
npm run build
npm run preview
```

## Структура

- `src/components` — Header, Hero, EventTimeline, GalleryStrip, Footer тощо
- `src/pages` — головна, новини, події, екіпажі, галерея, партнери
- `src/data/content.js` — контент українською
